# Zomato Delivery Performance

## About this project
This project examines 45,584 delivery records (cleaned to 41,359) with 20 variables covering traffic, weather, distance, city type, driver/vehicle info, workload, ratings, and festival periods. We identify external (traffic, weather, festival) and internal (vehicle condition, workload, driver rating/age) drivers of delay to improve on-time performance and customer satisfaction.

## This project includes
- Project background
- Business problem
- Data understanding & preprocessing (duplicate check, missing-value handling, basic type conversion)
- Data analysis & insights
- Interactive dashboard & Streamlit app (filters, drill-downs, KPI cards)
- Recommendations & actionable steps
